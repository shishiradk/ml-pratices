# Gradient Boosting Practice

This repository contains a Jupyter Notebook that demonstrates the use of Gradient Boosting techniques for supervised machine learning. The focus is on understanding and implementing Gradient Boosting models using `scikit-learn`, along with visualization and performance evaluation.

## 📁 File Structure

- `GradientBoosting-pratice.ipynb`: A practical notebook showcasing Gradient Boosting with example datasets and model evaluation techniques.

## 🚀 Features

- Data preprocessing using pandas and scikit-learn  
- Model training with Gradient Boosting Regressor  
- Comparison with other models (e.g., Decision Trees)  
- Visualization of results using matplotlib and seaborn  
- Model performance metrics such as MAE, MSE, and R²  

## 🛠️ Requirements

Install the dependencies using:

```bash
pip install -r requirements.txt
```

Or install manually:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

## 📊 Usage

To run the notebook:

```bash
jupyter notebook GradientBoosting-pratice.ipynb
```

Explore the notebook to see how Gradient Boosting is applied step by step, from data loading to model evaluation.
